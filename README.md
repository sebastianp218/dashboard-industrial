# Dashboard Industrial – Proyecto Integrador

Proyecto final de la asignatura Digitalización de Plantas Productivas.

## Objetivo

Desarrollar una aplicación web interactiva en Streamlit para analizar
el desempeño de una planta industrial compuesta por tres líneas de producción.

## Herramientas

- Python
- Pandas
- Plotly
- Streamlit
- GitHub

## Dataset

El proyecto utiliza el archivo:

`data/dataset_planta_bigdata.csv`

## Funcionalidades

- Indicadores de desempeño.
- Análisis de producción.
- Análisis de calidad.
- Monitoreo de variables operativas.
- Análisis de fallas.
- Filtros interactivos.
- Consulta y descarga de datos.
